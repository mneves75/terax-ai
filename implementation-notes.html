  • Browser-only Vite smoke may not exercise all Tauri IPC paths; native app smoke remains required for user-visible Tauri integration.

Final Decisions And Tradeoffs

  • Kept the Codex provider keyless because host Codex owns authentication and model configuration. Terax now verifies CLI availability/version before presenting it as connected.
  • Scoped Codex sessions by workspace root, cwd, workspace environment, and CLI path so a persisted Codex thread is not reused after the workspace/CLI changes.
  • Kept backend file and shell authorization in Rust, not only in the renderer. Renderer approval remains UX state; backend workspace checks are the enforcement boundary.
  • Allowed multi-line shell snippets while blocking recursive root/home deletes, disk-formatting patterns, Unicode bidi overrides, and pipe-to-shell install patterns.
  • Rejected renderer-controlled access to arbitrary private network addresses in ai_http_stream. Local model loopback endpoints remain allowed with opt-in.
  • Ignored local runtime artifacts .omc/ and .playwright-mcp/ through .gitignore; they are not part of the product diff.
